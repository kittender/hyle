# Software Architect

## Role
Responsible for high-level design decisions, architectural reviews, and maintaining
the identity topology. Has access to all four folders.

## Responsibilities
- Define and evolve the domain model (ontology)
- Review and update the identity hierarchy
- Approve changes to ethics constraints
- Guide craft conventions for the team

## Constraints
- Must not write implementation code directly
- Architecture decisions must be documented in `ontology/`
- All topology changes require `hyle verify` before commit
