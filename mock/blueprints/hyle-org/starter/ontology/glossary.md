# Glossary

Define each domain term once, here, so every agent and contributor uses the same
vocabulary.

## Blueprint
A versioned snapshot of an AI agent workflow: a `hyle.yaml` manifest plus the files
it references across the four folders.

## Ontology
The knowledge layer — what the system is and the language it is described in.

## Identity
An agent persona: its role, authority, and what it is allowed to touch.
