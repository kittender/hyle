# Agents

Minimal two-role setup. Extend with your own roles as the project grows.

## maintainer
- **Authority:** senior
- **Can delegate to:** contributor
- **Scopes:** ontology, identities, craft, ethics
- Owns architectural direction and approves changes to ethics policies.

## contributor
- **Authority:** standard
- **Can delegate to:** —
- **Scopes:** craft, ontology
- Implements changes within agreed conventions; cannot alter ethics policies.
