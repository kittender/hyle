# User Story Template

## Title
Short, action-oriented.

## Story
> As a **\<role\>**, I want **\<capability\>** so that **\<benefit\>**.

## Acceptance Criteria
```gherkin
Scenario: <happy path>
  Given <context>
  When <action>
  Then <observable outcome>

Scenario: <edge case>
  Given <context>
  When <action>
  Then <observable outcome>
```

## Out of Scope
List explicitly what this story does **not** cover.

## Notes
Open questions, dependencies, design links.
