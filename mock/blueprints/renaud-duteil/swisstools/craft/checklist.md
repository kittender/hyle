# Project Checklist

A language-agnostic readiness checklist. Tick before every release.

## Code
- [ ] Formatter and linter run in CI
- [ ] No commented-out code in the diff
- [ ] Public APIs documented

## CI/CD
- [ ] Build is reproducible
- [ ] Tests run on every push
- [ ] Artifacts are versioned with semver

## Security
- [ ] No secrets committed
- [ ] Dependencies scanned
